# 用户徽章只读事实与本地目录（2026-10-24）

基于缓存iOS70d0065的UserInfoDTO、BadgeCatalog、BadgeStrip。仅消费既有getUserInfo同响应的badge（JSON编码字符串）及admin_tag，无新增端点、私有读取或权限能力。目录为10项/13等级，名称/描述保持官方成品文字，图标仅保存本地文件名元数据，不下载/打开资源。

ProfileReadSnapshot新增可空badges：null为缺失/损坏/不支持的整段；空列表只证明没有展示项，不证明没有拥有徽章。等级大于0、权重不等于-1才展示；权重0或缺失/非法按有效999排序，原始可空权重保留；随后按本地目录顺序及原序稳定排序。未知字段保留接口名称，无说明，不从目录猜所有权。admin_tag非零按现有iOS实现仅展示管理员一枚（未知等级用目录基础说明）；这不改变isSelf、访问范围或任何认证权限。

只在徽章三个整数位使用精确整数解析：数字1.0/1e0按Foundation探针得到1，字符串1.0及非整数/溢出仍未知；布尔0/1遵循原FlexibleText合同，无舍入。其他SDK数值规则未改。
