# 论坛标题与正文搜索补齐设计

## 官方范围与契约

功能属于石之家官方论坛。2026-09-22 通过本机匿名无头移动 Chrome 核对 `/searchm` 与
`/sresult` 的公开 SPA：`GET api/common/search` 的 `type` 分别为帖子标题 1、帖子正文 2、
攻略标题 3、攻略正文 4。它与 `postsList` 的帖子 1、攻略 2 是两套枚举，不能复用 wireValue。
主机仍为 `apiff14risingstones.web.sdo.com`；沿用关键词、板块、排序、页码、每页数量、临时
会话标识和 `pageTime` 的现有查询与帖子列表响应解析。详细源码证据见官方移植记录。
此处只补论坛四种文本搜索，其他搜索分类按各领域契约单独处理。

当前匿名标题搜索成功只含 `rows`，不要求 `count` 或 `pageTime`。页面仅对该搜索端点的
业务码 10003 结束为空结果；按此局部契约处理，不改变其他接口的认证拒绝判定，也不因此
刷新或撤销已有会话。该码的证据来自公开源码，尚无本次线上返回样本。

搜索是匿名可用的只读请求，无新增写操作、主机或认证能力，不因搜索成功授予账号资格。
现有标题搜索中攻略误发 type 2，修正为 type 3；帖子默认保持 type 1。

## 分层与兼容性

不新增模块组。domain 增加 `OfficialForumSearchField`（标题、正文）及可选
`OfficialForumTextSearchService`，复用旧 `OfficialForumSearchQuery` 和浏览分页结果。
旧服务、查询构造、数据类及方法签名保持不变，旧调用默认标题搜索；data 实现可选扩展，
只在搜索端点显式映射四种 type，列表端点不受影响。

presentation 新增独立搜索选择状态，不修改原公开状态的数据类构造。状态保存选择、请求
世代与分页已加载查询，切换字段从第一页开始，迟到请求不能覆盖新选择。普通刷新失败保留
旧内容，取消继续传播。旧服务不展示或接受其不支持的正文搜索。

可选 Compose 界面在关键词区域提供本地化标题／正文选择，App 沿用既有论坛对象组装。
紧凑宽度继续列表到详情；中等和展开宽度继续双栏。选择随 ViewModel 跨旋转和宽度变化保留，
横向空间不足时允许选项换行，阅读宽度保持原限制。

## 验证计划

数据测试覆盖四种搜索类型、旧攻略调用、板块与排序保留、分页游标，以及列表类型不受影响。
状态测试覆盖提交、切换、重试、分页、迟到结果和旧服务降级；设备测试覆盖原生选择、搜索、
配置重建及 599、600、839、840dp 断点。维护三语资源与独立 Maven 消费，运行对应单测、
Lint、Debug 构建、仓库门禁并更新兼容矩阵。公开源码、匿名线上读取和合成测试分别记录，
不将搜索结果测试描述为账号写能力验证。
