# 本人职业与近况只读快照（本地验证）

`ProfileApiService.fetchSelfCharacterProfile()`组合读取既有`userInfo/getUserInfo`和`userInfo/getResently`，只读当前凭据对应的本人，不带其他用户uuid参数。新增`ProfileCharacterData`、`ProfileCharacterJob`、`ProfileCharacterEvent`独立模型；既有构造、`ProfileService`和资料／分页合同不变。

职业保留官方名称、非负Int等级与career_type，明确0级保留；缺失、坏行或重复职业使职业部分未知，不能据缺漏补出未开通。隐私标记仅根据明确关闭开关记录，本人仍能看到已返回值，不将它用于他人资料读取。

近况成功空数组是已知空；失败、结构错误或坏日期为未知null，调用方可保留同一身份的旧近况，但必须同时保留它的原始来源时间。取消必须向上传播。日期按明确offset或北京时间解析；缺失时刻和非法日历日期保持未知，不补造或归一化；稳定排序和相同时间／内容去重，不合成缺日期事件。近况失败不丢弃已成功的职业／本人信息；本人信息失败则整体失败。

SDK不负责本机身份选择、缓存、6小时时效、失败退避或页面布局；宿主须以原会话和角色归属约束完整多步骤读取及提交，不能认为每个GET的鉴权已代替工作流隔离。没有新增写入、自动发布或文件上传能力。

六项新增离线传输测试与完整1469项单测、lint／Debug构建通过。只验证源码消费，未验证真实账号、服务端当前payload、发布Maven制品或升级兼容。两份既有本机路径文档检查失败继续单列，没有改动或绕过。
