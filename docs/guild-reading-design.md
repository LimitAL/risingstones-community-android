# 我的部队与相册阅读设计

## 范围与证据

本批移植官方移动站“我的部队”的资料、成员、动态、相册、照片详情、评论与楼中楼阅读，
并打通消息中的照片来源。部队招募是独立能力，不共享其权限判断。上传、编辑、招待、点赞、
评论提交和删除另列后续操作流程，不能以只读实现完成代替整个部队功能完成。

2026-09-20 使用本机无头 Chrome 匿名读取官方移动站公开脚本。路由来自
`app.22e9274d.js`，部队主页来自 `chunk-c503ae20.2555e129.js`，成员组件来自
`chunk-9a191d82.db5708c9.js`，相册列表来自 `chunk-2d778fce.0381aba6.js`，详情来自
`chunk-482fae77.26b2759d.js`，账号入口来自 `chunk-06018ecd.e13c721a.js`，消息来源与接口
包装器来自 `chunk-0819b39c.a493ceca.js`。所有业务接口基址均为官方主机
`https://apiff14risingstones.web.sdo.com/api/home/`，与网页主机不同；沿用网络模块既有白名单，
不新增主机或依赖。

| 官方读取 | 参数与消费结构 |
| --- | --- |
| `userInfo/getUserBasicInfo` | 无参数；`data.gc_id` 为当前部队，0 表示未加入 |
| `guild/getGuildInfo` | `guild_id`；资料对象，包含住宅可见性条件 |
| `guild/getGuildMember` | `guild_id`；`registered` 与 `unRegister` 数组，不分页 |
| `guild/guildMemberDynamic` | `guild_id,page,limit=30`；`rows,count` |
| `guild/getGuildPhotos` | `guild_id,page,limit=20`；`rows,count`，空页终止 |
| `guild/getGuildPhotoDetail` | `id`；照片对象，响应 `guild_id` 为部队上下文 |
| `guild/GuildPhotoCommentDetail` | `photo_id,page,limit=20`，后续带 `pageTime`；`rows,pageTime`，空页终止 |
| `guild/guildPhotoSubCommentDetail` | `root_parent,order=earliest,page,limit=20`；`rows`，短页终止 |

上表均为 GET，只读验证不调用上传、编辑、点赞、评论、删除或消息已读接口。官方五条部队和
相册路由声明需要登录；匿名与真实账号响应类别由后续验证单列，不将路由声明等同于线上结果。
评论首请求的空 `pageTime` 不发送；有服务端游标时原样继续，不能编造时间戳。

部队等级的官网显示使用 `parseInt(guild_rank) || "---"`。2026-09-20 设备内检查确认该字段
不满足严格整数形状；数据层按十进制前缀读取有效等级，缺失或无法解析时保留未知状态，
不能因此撤销整份已成功读取的部队资料。此兼容仅适用于等级，部队 ID 和人数仍严格校验。

## 能力、身份与隐私

新增 `GuildRead`，使用当前凭证和对应 User-Agent 读取本人基本资料并校验部队关系；有部队时
还须成功读取其资料后授予，未加入部队时只授予已验证的无部队状态读取。格式缺失、异常、过期
均不得授予。每次验证先移除旧能力，会话撤销同步清除内存内容和阅读栈。单独照片读取成功不
授予写能力。现有账号或招募成功不自动推导此能力。

部队 ID 与照片、评论 ID 分开处理；消息 `guild_photo_id` 只定位照片，详情本身不需要父部队
ID。成员、照片和评论作者导航仅使用响应明确提供的社区 `uuid`，不将游戏角色 ID 或消息作者
当作照片作者。未注册社区的成员不可点击作者入口。住宅只有 `house_public` 开启或
`isGuildMember == 1` 时映射内容；隐藏值不能保留在公共领域对象中。

## 模块和职责

部队拥有独立实体、官方接口、权限和可复用发布价值，新增 `guild-domain`、`guild-data`、
`guild-presentation`、`guild-ui-compose` 四层模块。领域层提供资料、成员、动态摘要、照片、
评论、分页及读取服务；数据层负责官方请求、校验、隐私过滤及只读能力验证；展示层负责首次
加载、无部队、空结果、内容、刷新保留、分页、选择、详情、认证失效及取消传播。界面层提供
三语参考页面与可选作者/动态导航回调，不依赖其他功能界面。App 组装服务、入口和已有阅读栈。

紧凑宽度小于 600dp 时采用列表到详情导航；600dp 至 839dp 的相册使用列表与所选照片双栏；
840dp 及以上保留双栏选择并限制阅读宽度。旋转保留分区、照片与评论选择；返回作者或动态
详情后恢复来源，不能重新触发消息列表读取。照片仅有 ID 的深链可独立呈现详情。

## 验证计划与边界

合成夹具覆盖无部队、隐藏住宅、已注册与未注册成员、空页分页、评论游标、认证失败、刷新
保留、取消与撤权；公共 API 独立 Maven 消费覆盖数据和界面模块。目标 Compose 用例覆盖
599、600、839、840dp、消息到照片、作者返回、旋转与撤权。执行仓库门禁、单元测试、lint、
构建、发布和消费检查后记录实际结果。

真实账号只在设备内使用已保存的官方 WebView 会话读取已审查 GET；部队、照片、评论定位值
仅存在设备内存中，不输出响应值、凭证或带真实参数的地址。仅记录响应类别、结构和能力布尔
结果。空相册或评论不能证明非空结构，仍须区分源码与合成测试证据。

非空相册、照片详情、评论与楼中楼已完成源码和合成设备验证，仍缺当前账号的非空线上样本。
