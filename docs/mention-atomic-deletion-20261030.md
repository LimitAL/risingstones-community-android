# 已选提及的用户纯删除规则

本地批次 `mention-atomic-deletion-20261030`，基线 `b9a536a`。参考客户端缓存70d0065的 `RisingStonesMentionDraft.reconcile` 与 `RisingStonesMentionTests.deletingPartOfANameDeletesTheWholeMention`／`deletingASelectionAcrossTwoMentionsRemovesBoth` 明确：删除已选名字的一部分时，整段已选提及一起移除，保留不在选区里的普通文字／分隔空格，并将光标放回最早移除处。

原编辑器只丢弃提及身份而留下名字残片；本批只对携带合法变更范围、没有插入新字符的用户删除做修正。不猜缺失／错误变更范围，不按展示名搜索替换，也不改变插字、混合替换或显式提醒移除的既有规则。

`dynamic-presentation` 先验证与旧正文匹配、非重叠的选中跨度，再移除被删跨度在新正文中的残余部分，重算剩余UTF16偏移与光标。名字后的空格不是提及的一部分，除非用户选区本来包含它，否则保留；只删该空格不删除提及。普通手打同名@不受扩大删除。`@@名字` 等相同字符造成差分歧义时，优先采用生成相同新正文且不触及提及的删除位置，避免错删紧邻的已选身份。

显式插入／移除使用原有确定位置，不套用用户删除歧义规则，避免把移除操作移到相邻普通同名文字。该区分是私有编辑实现，不新增公开VM／领域／传输入口、权限、凭据、网络、缓存或重试，不迁移或清理用户草稿。

新增独立9项纯内存回归，首轮5项失败复现差异，修复后模块66项全通过；覆盖部分／跨提及删除、Unicode与剩余偏移、分隔空格、普通同名文字、重复@歧义、陈旧／非法范围，以及既有插入／混合替换／显式移除语义。模块lint／构建通过，仅旧构建文件compileSdk升级提示1条，未改基线或工具链。旧受拒发布合同测试插入未重试或绕过。
