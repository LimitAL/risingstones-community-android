# 品牌与图标说明

## 名称

- 简体中文：`石之家社区（非官方）`
- 繁体中文：`石之家社區（非官方）`
- 英文：`Rising Stones Community (Unofficial)`

应用商店、下载页和其他可能脱离仓库说明单独出现的位置，应保留“非官方”或
`Unofficial` 标识。包名和 Maven 坐标不是面向用户的官方身份声明。

## 图标

图标使用原创的猫爪石印标记，不使用服务运营方的官方标识：

- 单块圆润石头表示石之家及稳定积累的社区内容。
- 三枚粉色趾垫提供亲和的猫系气质。
- 中央掌垫使用对话形负形，表示社区交流，但整体仍首先识别为猫爪石印。
- 石印和手绘动势全部位于 Android 自适应图标安全区内，可以由启动器裁切为圆形、圆角矩形
  或其他形状。
- Android 13 及以上使用简化的单色猫爪作为主题图标。

![石之家社区非官方客户端图标](assets/app-icon-preview.png)

## 配色

| 用途 | 色值 |
| --- | --- |
| 暖黄色背景 | `#FFD966` |
| 石灰白主体 | `#FFF8ED` |
| 深梅色轮廓与掌垫 | `#302B3A` |
| 珊瑚粉趾垫 | `#F08A91` |

`docs/assets/app-icon-preview.png` 是组合后的品牌预览，
`docs/assets/app-icon-foreground.png` 是透明安全区母版。`app` 模块中按 Android 密度生成的
前景 PNG 是应用内权威实现。`docs/assets/app-icon-concept.png` 保留选定的原始概念图，用于
追溯造型方向，不应直接替换已校准安全区的启动器资源。

修改图标时必须重新检查：

1. 圆形和圆角矩形遮罩下石印与手绘动势没有被裁断。
2. 48 像素尺寸下石头外轮廓、三枚趾垫和中央掌垫仍能清楚分辨。
3. Android 主题图标仍能识别为带对话形掌垫的猫爪。
4. 新图形和说明不使用或仿制服务运营方的官方标识。
