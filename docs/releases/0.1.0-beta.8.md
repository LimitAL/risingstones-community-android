# Rising Stones Android 0.1.0-beta.8

为关注操作与作者资料读取的失败状态增加 typed `GlamourUiState.followFailure`，保留实际异常、业务 code／reason 及无 message 的失败；原 `followError` 字符串继续可用。重试、清除、成功刷新与认证状态重置遵循原流程，取消继续传播。异常仅保存在内存状态，不持久化，不增加网络请求。

保留 beta.7 的 34 参数构造、默认参数桥、无参构造、原 `copy`／`copy$default`、getter 与解构入口。旧消费者的普通复制保留 typed 失败；新消费者可显式复制清除失败。无需通过旧字符串猜测业务 code。

本地候选验证：官方 beta.7 编译的冻结消费者字节码在候选制品运行通过，公开 JVM 描述符没有移除；129 suites／1335 项 JVM 全仓重跑通过，40 release AAR 的 CRC／哈希／新鲜度通过。

发行门禁待完成：最终标签的签名 APK／AAB、release lint 与安全检查、正式非 SNAPSHOT Maven 发布及官方仓库独立消费。上述本地结果不代表这些发行步骤已完成。真实服务关注请求及设备／三语 18 配置 UI 验收仍 NOT-RUN。
