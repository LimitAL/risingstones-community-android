# 部队成员可选分组读取合同

成员读取继续使用既有认证 GET getGuildMember 与明确 guild_id，不新增权限、请求或写入。

本地参考实现的 registered、unRegister 均为可选数组。缺省或 JSON null 时保留另一组；已提供但非数组、数组中非对象仍报 InvalidResponse，不将坏结构伪装成空数据。原始成员字段映射不变。

GuildMembers.sourceRows 为可选来源元数据：整体 null 表示旧消费者／手工快照没有报告；每组 null 表示来源缺省或 null，0 表示明确空数组，正数为过滤前原始行数。它不代表部队总人数、唯一人数或完整性保证。展示过滤必须保留元数据，不能从过滤后列表补算。

新增字段参与值相等判断，缺省与明确空数组可触发状态更新。保留旧两参数构造、copy 和 copy$default 描述符；旧 copy 保留新增来源。旧 component1/2 不变。

仅用合成传输验证，不代表真实服务响应确认、独立 Maven 制品验证或严格双端视觉验收。认证、取消、读取资格及分页合同不变。
