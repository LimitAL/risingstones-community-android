# 动态发布与帖子转发设计

## 官方范围与证据

本功能只操作石之家官方社区内容。2026-09-22 在本机无头 Chrome 移动模式加载官方 SPA，
读取发布分块 `chunk-2693dc42.a0ac27d8.js`、转发分块 `chunk-4420b4e8.33afac25.js`、
公共编辑依赖 `chunk-4a5f46a6.4f6a85f9.js`，并核对入口脚本的接口与上传组件。
发布与转发页面均要求登录；本批未用真实账号提交、上传或改变可见范围。

| 行为 | 官方主机与请求 | 字段与成功语义 |
| --- | --- | --- |
| 发布动态 | `apiff14risingstones.web.sdo.com`，POST `api/home/dynamic/create` | `atInfo[index][uuid/character_name],content,scope,pic_url`；HTTP 200，业务码 10000/10002；页面不依赖返回 ID |
| 转发帖子或攻略 | 同一主机，POST `api/home/posts/relay` | `atInfo[index][uuid/character_name],content,scope,posts_id`；HTTP 200，业务码 10000/10002；页面不依赖返回 ID |
| 动态发布图片令牌 | 同一主机，GET `api/common/getCOSTokenI?channel=dynamic` | 沿用已审查 COS 临时凭证结构与官方对象存储主机 |

写请求使用 `application/x-www-form-urlencoded`。`scope` 为 1 公开、2 仅互关、3 仅自己；
原生使用明确枚举，默认公开。发布要求非空正文，不能用仅选图片绕过；最多九图，允许删除和
调整顺序，`pic_url` 是按最终顺序拼接的逗号分隔 URL。转发页面的图片区域被隐藏，提交不带
图片；空转发文字使用官网明确的“分享了内容：”。

发布/转发编辑器将表情写为 `<span class="at-emo" contenteditable="false">[emoN]</span>`，
提及写为带 `data-uuid` 的 `at-text`。不将评论所用的图片表情 HTML 直接当作发布契约。
上传组件在页面指定 png/jpeg/jpg/gif 外额外接受 webp，每图最多 22,020,096 字节。
原生在用户明确发送时才取得令牌及上传；本地选择、预览、移动和删除不产生服务器写入。
图片队列保存本地来源而非原图字节，发送时逐张读取，避免九张原图同时占用内存。

转发页只展示帖子与攻略两种来源，且提交字段固定为 `posts_id`。其他动态来源的阅读类型不
证明可以传给此接口；招募包装器另有 `recruit/relay`，其页面调用、其他动态和幻化转发仍须
单独核实，不为这些类型复用帖子编号或编造类型参数。

## 能力与状态边界

复用独立 `DynamicWrite` 与 `DynamicImageUpload`，不增加按页面划分的能力。基础明确尝试
资格依赖已验证 `DynamicRead`。登录、阅读、取得图片令牌不能当作成功发布；无副作用的
能力探测保持不变。发布与转发成功才完成写能力尝试，上传成功只授予图片能力。

复用凭证与读能力世代绑定的 `DynamicActionScope`。新建草稿、改变来源、丢失能力、换号或
明确丢弃时关闭旧作用域；禁止将旧稿重新绑定到新凭证。ViewModel 使用会话专属容器，配置
重建保留同一实例。图片上传结果同时绑定作用域和用途，发布与评论的上传 channel 不可混用。
失败不自动重发；用户明确重试可复用同作用域已经上传成功的图片，保留原顺序。关闭草稿
不代表已经上传的远端对象被回滚。返回未知结果时不猜测动态 ID，也不自动重复提交。

## 分层与原生交互

不增加模块组：发布的实体、接口、状态与现有动态领域一致。domain 新增发布可见范围、
发布/帖子转发草稿及可选服务；data 复用已有授权、表单和 COS 隔离，增加准确接口及用途
校验；presentation 管理正文、提及、图片队列、顺序、上传缓存、明确丢弃和单次提交；
Compose 复用原生编辑器、表情资源与图片导入；app 组装来源导航、会话容器及成功后刷新。
保留已有服务和屏幕签名，论坛通过可选宿主回调交付已读取的帖子来源，不依赖动态 data。

关注动态页增加原生发布入口，已确认的帖子/攻略详情增加转发入口。编辑器明确显示来源和
可见范围，关闭有内容的草稿时确认丢弃；成功关闭编辑器并刷新动态阅读数据，失败保留草稿
并在编辑器内显示错误。紧凑宽度使用完整单栏编辑流程，中等与展开宽度限制编辑区域最大
宽度并保留来源上下文。图片排序同时提供可访问的移动操作；文本、错误和说明维护三语。
