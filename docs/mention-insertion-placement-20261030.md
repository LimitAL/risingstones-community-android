# 选人插入位置与分隔

本批对齐官方客户端已有的本地编辑规则，不增加网络、权限、凭据或发布能力。

`DynamicCommentEditorState.previewMentionInsertion(mention, replacingAtSignAt)` 返回新的编辑快照，不改变原值。普通选人保留选区正文，按选区末端插入；末端位于仍与原文匹配且不重叠的提及内部时移至其末端及一个后随ASCII空格之后。前一个Unicode标量不是Unicode空白时补一个ASCII空格，名字后仍附一个ASCII空格；身份范围只包含@和名字，不包含分隔。普通@文字或失效范围不提供保护权。

只有明确提供、紧邻折叠光标且不在有效提及内的半角@／全角＠可被替换，保持键入触发优先，无额外前导空格。缺失或失效来源回退普通选人插入。两个ViewModel保留原单参数入口，新增带来源偏移的重载，原提交中／可编辑门控不变。调用方仍负责候选UUID与名字合法性、当前身份、生命周期及配额；SDK不从展示名猜身份，也不决定产品最大字数。

接入方应以同一预览全文核查配额后再选择，不能先删除触发符或减去选区字符再预测。普通键盘输入／粘贴／删除规则不变。现有选人按钮和工具栏行为更正为插入，不能再依赖其替换所选正文。

验证仅纯内存合成人名、App本地替身及实际进程DNS／Socket阻断；具体结果由同名批次证据索引记录。没有真实候选读取、发布、评论、图片上传或严格双端运行验证；Maven制品与旧平台原生未验。历史媒体请求外发结果仍未知，本批不查询、重试或清理。
