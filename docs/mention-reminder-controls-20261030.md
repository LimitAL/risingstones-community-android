# 动态草稿已选提及移除

本地批次 `mention-reminder-controls-20261030`，基线 `272bdc9`。对应本地iOS缓存 `70d0065` 的提及提醒胶囊及 `RisingStonesMentionDraft.remove`，不是远端删评论／删动态接口。

动态发布与评论状态机新增 `removeMention(uuid)`，仅编辑当前可编辑草稿。按UUID移除该人的全部有效已选跨度，绝不按展示名搜索替换；同名不同UUID及普通手打@文字保留。每个跨度只额外吞掉一个后随ASCII空格，不吞第二个空格、制表符、不换行空格或换行。保留其余正文／提及并调整UTF16偏移，光标落在最早移除处；验证过的范围防止陈旧／重叠元数据误删普通文本。

发布状态机要求usable、非提交中及无已完成结果；评论要求编辑器打开且非提交中。接入方还须保留自身身份、目标和未知结果门控。该操作不提交、不读取候选、不获取凭据、不增加能力、缓存或自动重试；原有发布成功清空草稿行为不变。未命中UUID不改变正文。

同UUID的提醒胶囊应按UUID去重并稳定标识，按钮名使用完整@展示文字，操作仍传UUID。默认参考界面本批未扩展，宿主可调用新方法实现自己的提醒行；应禁用提交中／权限失效／结果未知时的按钮。
