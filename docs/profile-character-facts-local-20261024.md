# 本人资料卡六字段（本地合同资格）

`fetchSelfCharacterProfile()` 的既有本人 GET 响应新增可选 `facts`：创建日期、最近登录、累计时长、房屋、水晶冲突最高段位、无人岛等级。仍只用既有 getUserInfo/getResently，不接他人 UUID、不增加认证能力或写端点。

characterDetail 接受单项数组及对象；整段缺失/坏形状为 null，不能说成六字段都是零。有效对象内缺失、空白、短横线、星号值为 null；数字零及原文保留。按缓存 iOS flexible scalar 合同，JSON boolean 值转换为 0/1，字符串原文保留；公开开关只有明确 0/false（含字符串、首尾空白）才标记 unpublished。本人仍可见实际返回的未公开值，此标记不授予其他用户访问权限。

日期保持来源原文，不在数据层补日期或归一化非法日历值；宿主按北京时间的日期语义呈现。时长只在展示层解析，无法安全解析时保留原文。六字段属于同一资料来源观察时间 fetchedAt，近况失败不丢弃资料。宿主保留独立来源时间，不将职业/近况更新时刻覆盖旧资料事实。

新增属性默认为 null；保留旧九参数 JVM 构造、copy 及 copy$default 入口，component1–9 不变。离线测试覆盖旧入口可用和事实保留；这不是已发布 Maven 制品、旧二进制消费者完整升级或真实服务验证。

最终完整 1481 单测、lint/Debug 构建通过；公开边界、分层、公开源码安全检查通过。仓库布局检查仍仅有原来两份文档的本机路径问题，未抑制或改基线。所有数据与传输均本地 fixture/mock，无真实账号、业务外发、发布或推送。
